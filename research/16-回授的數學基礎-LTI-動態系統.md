# 16 — 回授的數學基礎：LTI 動態系統

> 承接第 15 篇。上一篇用「疊代收斂器」統一了 Mythos 與 Fusion；本文把這個抽象**數學化**，
> 用離散動態系統與控制理論的語言，精確描述「回授」何時收斂、何時發散。
> 這是本系列最理論的一篇，也為第 17 篇的「整合 vs 注入」映射與第 21 篇的設計約束提供嚴格基礎。

## 1. 迴圈就是離散動態系統

把 Mythos 的 RecurrentBlock 更新規則（`main.py:742`）寫成標準形式：

```
h_{t+1} = A · h_t + B · e + Transformer(h_t, e)
```

忽略非線性的 Transformer 項（`README.md:276-283` 的線性化），得到離散線性非時變（LTI）系統：

```
h_{t+1} = A · h_t + B · u_t       （u_t = e，常數輸入）
```

這就是控制理論裡最基本的離散時間狀態空間模型。`h` 是狀態，`A` 是狀態轉移矩陣，`B` 是輸入矩陣，`u` 是外部輸入。

## 2. 收斂的充要條件：譜半徑

對齊次系統 `h_{t+1} = A · h_t`（無輸入），解為 `h_t = A^t · h_0`。
「狀態不爆炸」的條件是 `A^t → 0` 當 `t → ∞`。這等價於（譜半徑條件）：

```
ρ(A) := max |λ_i(A)| < 1
```

其中 `λ_i(A)` 是 A 的特徵值。理由：把 A 對角化後，`A^t` 的每個對角元素是 `λ_i^t`，
`|λ_i| < 1` 時該分量衰減到 0。

### 對角矩陣的特例

OpenMythos 的 `get_A()` 回傳**對角**矩陣（`main.py:714-725`），對角矩陣的特徵值就是對角元素本身。
所以 ρ(A) = max(對角元素) = `A.max()`。這就是為什麼測試能用 `A.max() < 1` 而不必算 eigvals
（第 05 篇已說明）——但這只對對角參數化成立；設計非對角 A 時必須回到 eigvals。

## 3. 帶輸入的系統：為什麼「注入」不破壞穩定性

有輸入時 `h_{t+1} = A · h_t + B · u`。若 ρ(A) < 1，系統是**BIBO 穩定**（bounded-input bounded-output）：
有界的輸入產生有界的狀態。證明梗概：

- 齊次解 `A^t h_0` 衰減（因 ρ(A)<1）。
- 特解（強迫響應）是 `Σ_{k=0}^{t-1} A^k B u`，因 `Σ A^k` 收斂（幾何級數，公比 <1），故有界。

這正是「在每個迴圈注入 `B·e` 不會讓系統爆炸」的數學根據——**只要 ρ(A)<1，
持續注入有界訊號只會把狀態推向一個有界的穩態附近，而非無界增長**。

OpenMythos 的 `e` 來自 Prelude，是有限維張量，自然有界。所以注入安全。

## 4. OpenMythos 如何「構造性」滿足條件

第 05 篇已詳述，這裡用動態系統語言重述（`main.py:696-698`）：

```
A_continuous = Diag(-exp(log_A))        # 負對角，保證衰減方向
A_discrete   = exp(Δt · A_continuous)   # ZOH 離散化
```

關鍵數學鏈：
1. `log_A` 任意實數 → `exp(log_A) > 0` → `-exp(log_A) < 0`：連續系統的每個極點是負實數（穩定）。
2. `Δt = exp(log_dt) > 0`：步長恆正。
3. `Δt · A_continuous` 的對角元素仍是負的。
4. `exp(負數) ∈ (0, 1)`：離散系統的每個特徵值嚴格在單位圓內 → ρ(A) < 1。

這是「把連續穩定系統離散化後仍穩定」的標準結果（ZOH 離散保留穩定性）。
OpenMythos 的貢獻是把它**編進參數化**，使梯度下降無論怎麼走都落在穩定區。

## 5. 非線性的考慮：Transformer 項怎麼辦

真實更新有 `Transformer(h_t, e)` 這個非線性項。嚴格說，譜半徑條件是對**線性近似**成立的。
為什麼實務上仍可靠？

- **Lipschitz 上界**：若 Transformer 塊是 Lipschitz 連續（實務上神經網路在正常輸入範圍多半如此），
  且其 Lipschitz 常數 L 滿足 `ρ(A) + L < 1`（或更精細的小增益條件），非線性系統仍有收斂保證
  （這是離散非線性系統的收縮映射 / 小增益定理精神）。
- **ACT 的安全閥**：即使偶爾偏離，ACT（第 09 篇）讓位置在收斂後停止，避免長期累積偏離。
- **經驗**：第 05 篇的 lr=1e3 測試顯示，即使極端梯度步驟後 A 仍 < 1，且訓練收斂。

所以 OpenMythos 的穩定性是「線性構造保證 + 非線性小增益 + ACT 安全閥」的三重保護。

## 6. 把同一套語言套到 Fusion

Fusion 不是線性系統，但可視為**單步迭代**的動態系統：

```
s_1 = F(s_0, x, {m_1(x), ..., m_N(x)})
```

其中 `m_i` 是 panel 模型，`F` 是 judge+outer。它只疊代一次（第 14 篇的遞迴保護），
所以**沒有「特徵值爆炸」的風險**——不存在 `A^t` 的累乘。

但若**假設性**地允許 Fusion 遞迴（它禁止的），就會變成：

```
s_{k+1} = F(s_k, x, panel(s_k))
```

此時收斂性完全取決於 `F` 的「譜半徑」（廣義：複合算子的 Lipschitz 常數），
而這對自然語言 LLM 是未知且不可控的——這正是 Fusion 用硬性單層界來規避的根本原因。
**Mythos 靠構造保證 ρ<1 可以放心遞迴；Fusion 無此保證所以禁止遞迴。** 數學上完全一致。

## 7. 一個給設計者的檢核表

基於以上，第 21 篇設計「回授 LLM」時的硬性檢核（本篇的實用產出）：

| 設計選擇 | 必須回答的數學問題 |
|----------|-------------------|
| 讓狀態遞迴 | 你的回授矩陣 ρ < 1 嗎？如何構造性保證？ |
| 持續注入訊號 | 注入項有界嗎？系統 BIBO 穩定嗎？ |
| 允許非線性 | 非線性項的 Lipschitz 常數可控嗎？小增益條件成立嗎？ |
| 允許深度遞迴 | 線性近似的譜半徑 + 非線性 Lipschitz 夠小嗎？ |
| 若用離散 LLM 呼叫遞迴 | 有收斂保證嗎？沒有就必須設硬性深度界 |

這張表把「為什麼 Mythos 能深、Fusion 必須淺」變成可操作的设计约束。

## 8. 本文結論與下篇預告

- 迴圈 = 離散動態系統；收斂 ⇔ ρ(A) < 1（譜半徑條件）。
- 帶注入的系統在 ρ(A)<1 時 BIBO 穩定——這是「每迴圈注入 `e` 不爆炸」的根據。
- OpenMythos 用 ZOH 離散化構造性保證 ρ<1；非線性靠小增益 + ACT 三重保護。
- Fusion 單步迭代無累乘風險；若允許遞迴則失去保證，故硬性限單層。
- 兩者的深淺選擇在數學上完全自洽。
