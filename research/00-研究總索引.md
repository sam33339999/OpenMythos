# 研究總索引：OpenMythos 迴圈深度 Transformer 與 OpenRouter Fusion 多模型審議

本目錄收錄一系列循序漸進的研究筆記（繁體中文 Markdown），主軸為：

> **在 LLM 架構中建構「Mythos 式」的響應與回授（recurrence / feedback）機制**，並將其與
> **OpenRouter Fusion**（把多個 LLM 回應並行產出後、由一個整合 LLM 收斂為最終結論）的機制進行對照，
> 最後延伸出一份「如何從零開始打造此類機制」的設計文件（僅設計、不實作）。

每一篇文件都會：
1. 回應上一篇留下的開放問題或結論，形成連續論述。
2. 引用**已驗證**的證據——OpenMythos 程式碼以 `檔案:行號` 標注（來自本倉庫實際原始碼），
   OpenRouter API 以官方文件 URL 標注（已實際抓取確認存在）。
3. 給出邏輯連貫的說明，不偏離研究主軸。
