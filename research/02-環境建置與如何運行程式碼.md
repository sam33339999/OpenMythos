## 2. 安裝

```bash
# 可編輯安裝（開發）
pip install -e .
# 或
poetry install

# 想用 Flash Attention 2（需 CUDA + 建置工具）
pip install open-mythos[flash]
```

**重要前提**：`flash-attn` 只影響 `GQAttention`，**不影響** `MLAttention`
（`main.py:8-13` 的 `try/except`，以及 `AGENTS.md` 的不變量說明）。
沒裝時會**靜默退回**手動 scaled dot-product attention，由 `_HAS_FLASH_ATTN` 旗標守護。

## 3. 跑範例：`example.py`

最直接的煙霧測試就是 `example.py`（已完整讀取，共 50 行）。它做四件事：

1. 建一個**迷你** MLA 設定（`dim=256`, `vocab_size=1000`, `max_loop_iters=4`，`example.py:7-34`）。
2. `forward` 跑一次前向傳遞並印 logits 形狀（`example.py:41-42`）。
3. `generate` 自迴歸生成 8 個 token（`example.py:44-45`）。
4. 印出注入矩陣 `A` 的相關數值（`example.py:47-49`）。

```bash
python example.py
```

### ⚠️ 一個必須修正的已知錯誤

`example.py:49` 這樣計算「譜半徑」：

```python
print(f"... Spectral radius ρ(A) max: {A.max().item():.4f} ...")
```

這是**錯的**——它只是讀了對角矩陣的一個元素。`AGENTS.md` 與 README `README.md:99-103` 都指出，
正確做法是用特徵值：

```python
A = model.recurrent.injection.get_A()
rho = torch.linalg.eigvals(A).abs().max().item()
```

（注意：在現有實作裡 `get_A()` 回傳的是 1-D 對角向量 `main.py:714-725`，所以對它做 `eigvals`
需先 `torch.diag(A)`。研究與設計時應以 README 的公式 `ρ(A) < 1` 為準。）

## 4. 跑測試

```bash
# 全部（CPU、快速、無網路）
pytest

# 單一案例
pytest tests/test_main.py::TestRMSNorm::test_output_shape
```

`tests/test_main.py`（已完整讀取，678 行）是**純 CPU 單元測試**，用極小的 `MythosConfig`
覆寫（`dim=64` 等，`tests/test_main.py:28-57`）。重點測試類別包括：

| 測試類別 | 驗證什麼 | 關鍵斷言 |
|----------|----------|----------|
| `TestLTIInjection` | 穩定性保證 | `test_spectral_radius_stable_after_large_grad_step`（`tests/test_main.py:479-489`）：即使 lr=1e3 的激進梯度步驟後 `A.max() < 1` 仍成立 |
| `TestRoPE` / `TestRoPEExtended` | 旋轉位置編碼正確性 | 保長、逆旋轉還原、相對位置性質（`tests/test_main.py:90-251`） |
| `TestOpenMythosGQA` / `TestOpenMythosMLА` | 完整模型前向、生成、深度外推 | `test_depth_extrapolation_changes_output`（`tests/test_main.py:576-580`）：n_loops=1 vs 3 輸出必須不同 |
| `TestAttnTypeSwap` | MLA 快取比 GQA 小 | `test_mla_fewer_kv_cache_bytes`（`tests/test_main.py:659-674`） |

> ⚠️ 有兩個測試檔**不是** pytest：`tests/bench_vs_transformer.py`、`tests/small_benchmark.py` 是
> **CLI 基準腳本**，要直接 `python tests/small_benchmark.py --device cuda --steps 5000` 執行
>（`AGENTS.md` 已記載）。
>
> ⚠️ `tests/test_tokenizer.py` 會**下載** `openai/gpt-oss-20b`，**離線會失敗／卡住**——因為
> `MythosTokenizer.__init__` 呼叫 `AutoTokenizer.from_pretrained`（`tokenizer.py:30`）。

## 5. 跑訓練

訓練腳本在 `training/3b_fine_web_edu.py`（已完整讀取，551 行），用 **FSDP + AdamW** 在 FineWeb-Edu 上預訓練 3B 模型。

```bash
# 單 GPU
python training/3b_fine_web_edu.py

# 多 GPU（自動偵測 GPU 數）
torchrun --nproc_per_node=$(python -c "import torch; print(torch.cuda.device_count())") training/3b_fine_web_edu.py
```

### 訓練腳本的「地雷」（來自 `AGENTS.md` 與實際讀碼）

1. **獨立相依**：`training/requirements.txt` 與主程式不同，需 `datasets>=3.6.0`（比函式庫的 `>=2.18` 新）
   與 `loguru`（`training/3b_fine_web_edu.py:18, 30`）。要分開安裝。
2. **串流資料不可 seek**：`FineWebEduDataset`（`training/3b_fine_web_edu.py:43-108`）用 `streaming=True`
   拉 `HuggingFaceFW/fineweb-edu`，串流不可隨機讀取，所以**續跑會從分片的開頭重播**
  （`training/3b_fine_web_edu.py:51-57` 的註解明說）。
3. **Optimizer 必須在 FSDP 包覆後才建**：`main.py:438-440` 在 `FSDP(...)` 之後才建 AdamW，
   否則 optimizer 會追蹤到舊的（被 FSDP 重整平的）參數物件（`main.py:316-321` 的 docstring 說明此順序 invariant）。
4. **梯度裁剪要走 FSDP 路徑**：多 GPU 時用 `model.clip_grad_norm_(1.0)` 而非
   `nn.utils.clip_grad_norm_`，因為後者只看各 rank 的局部 norm（`training/3b_fine_web_edu.py:508-514`）。
