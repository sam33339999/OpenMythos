## ❓ 一些你可能會有的問題

**Q: 我需要 GPU 嗎？**  
不一定。用 CPU 跑小型測試是可以的，只是速度比較慢。如果想認真訓練，才需要 GPU。

**Q: 我需要懂 Python 嗎？**  
建議有基本的 Python 概念（變數、函數、安裝套件）。如果完全沒碰過，建議先看 [Python 官方入門教學](https://docs.python.org/zh-tw/3/tutorial/)。

**Q: OpenMythos 和 ChatGPT 有什麼差別？**  
OpenMythos 是一個「架構研究專案」，不是一個可以直接聊天的產品。它探索的是「AI 如何思考」的機制，你可以從這裡學習、實驗，甚至訓練屬於自己的模型。
