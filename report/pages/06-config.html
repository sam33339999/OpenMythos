10. 可觀察的尺度法則

從變體表能歸納出五條擴展策略（也是 Part III 訓練策略的依據）：

  1. dim 約略 ×√2 成長：每兩階約翻倍，決定每層計算量。
  2. 專家數在 50B 後才大幅增加：廣度被當作大模型的差異化能力。
  3. 迴圈數單調上升（16→64）：一般 Transformer 不存在的擴展軸。
  4. 上下文只在 100B 跳到 1M：長脈絡是最大規模才啟用的能力。
  5. 共享專家 2→8、每 token 啟動 4→8：越大越強調共用知識。
參數預算公式 total ≈ embed + prelude/coda 稠密區塊 + recurrent MLA + MoE
MoE = 3 * dim * expert_dim * (n_experts + n_shared * n_experts_per_tok)
expert_dim 是從「扣除其他項後的剩餘預算」反解出來的，讓總參數對齊目標量級。
已知 doc/code 不一致 所有變體的 attn_type 都是 "mla"，與 README「Model Variants」範例誤稱 mythos_7b()（根本不存在）的 GQA 框架不一致。實際可用的是上表 7 個變體，全部使用 MLA。
